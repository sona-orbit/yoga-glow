# Yoga Glow (瑜光 30)

Website for **Yoga Glow** — turn a long yoga class video into a ~30-second glow, entirely on your iPhone.

Served by GitHub Pages at https://sona-orbit.github.io/yoga-glow/

- Home, privacy and support pages in English, 繁體中文, 简体中文, 日本語, 한국어 and ไทย
- Static HTML/CSS, no build step on this repository
